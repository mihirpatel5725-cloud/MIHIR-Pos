# RK Billing — Radhe Kathiyawadi

Offline-first mobile POS with LocalStorage persistence, PWA installation, menu/order/report management, image-based logo and UPI QR uploads, and responsive 58mm/80mm receipt preview.

## Upload and run
Upload all files to `mihirpatel5725-cloud/MIHIR-Pos`, preserving `icons/rk-logo.svg`. Run with any static web server; for example `python3 -m http.server 8080`, then open `http://localhost:8080`. GitHub Pages or another HTTPS host is recommended for PWA installation.

## Android installation
Open the HTTPS app URL in Chrome, choose **Install app** or **Add to Home screen**. The service worker caches the application shell for offline use. Data is stored in that browser/device and is not sent to a server.

## Logo and QR
Open **More → Settings**. Upload a logo and/or the exact UPI QR image from the phone gallery. The images are converted to data URLs and stored locally. They can be previewed, replaced, or removed. No QR is generated by the app. Enable QR to show it on billing and receipts.

## Printing
Open **More → Printer Settings**. Select 58mm or 80mm, print logo and QR ON/OFF, and choose sizes. Use Print test or Reprint. The preview uses a compact monospace receipt layout and browser print dialog; pair Bluetooth or USB/OTG printers with Android first. Actual printer routing is provided by the Android/browser print system; a future native APK wrapper can connect directly to ESC/POS Bluetooth/USB APIs.

## Backup and restaurant details
Settings provides JSON Backup, Restore and Reset. Edit restaurant name, address, phone, GST number, invoice prefix, UPI ID, logo and QR there. Restore only trusted backups.

## Packaging as APK
This static PWA can later be wrapped with Capacitor or Trusted Web Activity. Keep the app served over HTTPS and request Bluetooth/USB printer permissions in the native wrapper when adding direct ESC/POS transport.
